
# LMS - Learning Management System

A full-stack Learning Management System built using
the MERN stack.

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS
- shadcn/ui

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication
- Google OAuth (Students)
- Email/Password (Educators)
- JWT
- bcrypt

## Project Structure

- client: Frontend application
- server: Backend application

## Project Status

Currently under development.
